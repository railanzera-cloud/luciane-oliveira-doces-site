# Release comercial

Abra o [protocolo de integração](../../../docs/continuidade/PROTOCOLO-DE-INTEGRACAO-E-RELEASE.md) e a [matriz de impacto](../../../docs/continuidade/MATRIZ-DE-IMPACTO-COMERCIAL.md). Confirme a fonte servida nos domínios públicos e verifique os contratos indispensáveis ao escopo antes de escolher a base.

Use as verificações e o empacotamento da linha de release. Registre evidências de código, ZIP, Edge e implantação no estado e checkpoint existentes. Para cada mudança em catálogo, flags ou backend, identifique a versão compatível dos outros componentes e a ordem de rollback.

Use os caminhos de homologação descritos no protocolo. Uma publicação, migração ou ativação segue as autorizações específicas descritas no [AGENTS.md](../../../AGENTS.md).
